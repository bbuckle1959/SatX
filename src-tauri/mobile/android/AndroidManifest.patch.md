# Android network permissions (Tauri 2)

Run once:

```bash
npm run tauri android init
```

Then edit **`src-tauri/gen/android/app/src/main/AndroidManifest.xml`**.

## 1. Permissions (inside `<manifest>`, before `<application>`)

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
```

Tauri usually adds `INTERNET` already; add `ACCESS_NETWORK_STATE` if missing.

## 2. Application tag

Find `<application ...>` and ensure these attributes are present (merge with existing attributes):

```xml
<application
    android:usesCleartextTraffic="true"
    android:networkSecurityConfig="@xml/network_security_config"
    ...>
```

If you see `android:usesCleartextTraffic="${usesCleartextTraffic}"`, either:

- set `usesCleartextTraffic=true` in `src-tauri/gen/android/gradle.properties` / `tauri.properties` (if your template supports it), **or**
- replace the placeholder with literal `android:usesCleartextTraffic="true"` for release builds.

`usesCleartextTraffic="true"` allows HTTP to `http://192.168.100.1` from the WebView and from native Rust (`reqwest`).

## 3. Network security config file

Copy the committed template into the generated tree:

**From:** `src-tauri/mobile/android/res/xml/network_security_config.xml`  
**To:** `src-tauri/gen/android/app/src/main/res/xml/network_security_config.xml`

Create the `res/xml` folder if it does not exist.

This is narrower than global cleartext: it allows HTTP only for the dish IP and dev hosts.

## 4. Rebuild

```bash
npm run tauri android build
```

> **Note:** `src-tauri/gen/android/` may be regenerated by `tauri android init`. Keep `src-tauri/mobile/android/` as the source of truth and re-apply after re-init.
